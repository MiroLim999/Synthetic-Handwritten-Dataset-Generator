# Third-party license records

This directory is the index for license texts and attributions of third-party
materials intentionally distributed with the repository. It is not a license
for the project's own source code.

At present, no font binaries are tracked, so no font license is asserted here.
Font-specific texts belong under `resources/fonts/LICENSES/` and must be named
unambiguously (for example, `ExampleFont-OFL-1.1.txt`). Update `NOTICE.md` with
the corresponding filename, upstream version, source URL, copyright notice,
and license identifier whenever a third-party asset is added.

Do not copy a generic license text into this directory unless it is the exact
text delivered with, or authoritatively applicable to, the distributed version.
The absence of a license file means permission has not been established—not
that a work is unrestricted.
